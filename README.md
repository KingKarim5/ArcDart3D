# ArcDart3D

A 3D dart game developed using Python and OpenGL as a CSE423 Computer Graphics project.

## Features

* 3D dartboard and dart-throwing mechanics
* Multiple game modes, including Rush, Trickshot, and Call Your Shot
* Aiming controls and trajectory prediction
* Scoring, accuracy tracking, and combo streaks
* Dynamic obstacles and rotating dartboard mechanics
* Hit-distribution heatmap
* Replay and rewind mechanics
* Particle effects and visual feedback

## Technologies Used

* Python
* PyOpenGL
* OpenGL
* GLUT / GLU

## Installation

1. Install Python 3.

2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:

   ```bash
   python CSE423-project_group-3_ArcDart3D.py
   ```

A compatible desktop environment and OpenGL/GLUT support are required.
